# CampusTask – Student Task Management System

CampusTask is a simple web application designed to help students manage their academic tasks and daily activities in an organized way.

The application allows students to create, update, delete, and track their tasks. It helps students stay organized, manage their work, and keep track of pending and completed activities.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Track task completion
- Simple and user-friendly interface
- Store and manage tasks through a backend API

## Technologies Used

- React.js
- HTML
- CSS
- Node.js
- Express.js
- MongoDB
